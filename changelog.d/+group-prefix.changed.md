A group of the core takes the prefix `grp_` in its slot, as an operation
takes `op_` and a command `cmd_`, without a domain: the group of every
signed-in user, `signed_in`, is `grp_signed_in`, its slot
`AuthGroupsUnit.grp_signed_in`, where an application declares the class
that grants it more. Its name is that of the slot, `grp_signed_in` in the
list of the groups; it keeps no members, so none stored moves.
